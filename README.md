# Muskan Gurjar — Developer Portfolio

> **B.Tech IT Student · Aspiring Software Developer**  
> *"Building my skills. Creating things that matter."*

A modern, high-performance personal portfolio website built with semantic HTML5, modern vanilla CSS3 design tokens, and accessible vanilla JavaScript. Engineered with a dark theme aesthetic featuring deep black, vivid burnt orange, and warm electric yellow accents.

## 💻 Tech Stack

- **HTML5:** Semantic markup, landmarks, and accessible ARIA attributes.
- **CSS3:** Custom properties (design tokens), CSS Grid, Flexbox, responsive fluid typography (`clamp()`), and reduced-motion media query support.
- **JavaScript (ES6+):** IntersectionObserver scrollspy, accessible mobile drawer with backdrop overlay, and clipboard API.

## 🛠️ Local Development

Clone the repository and serve it locally:

```bash
git clone https://github.com/muskangurjer/muskangurjer.git
cd muskangurjer
```

Run a simple local server:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js / npx
npx serve
```

Open `http://localhost:8080` in your browser.
